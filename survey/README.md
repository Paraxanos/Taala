# Survey instrument (D0.2)

The word list and the train/test split are **frozen**. The survey itself runs **after the presentation**; until then the rules are developed on the pilot variant set in `data/variants/`.

| File | What it is |
|---|---|
| `words.tsv` | The 100-word master list: Devanagari form, a reference romanization, an English Wikipedia title where one exists, a category, and the spelling phenomena each word targets |
| `split.tsv` | The frozen 50/50 train/test split, by word, stratified by category. Generated by `tools/freeze_wordlist.py` |
| `FREEZE.json` | SHA-256 hashes of `words.tsv` and `split.tsv`, plus the seed and the freeze date. `tests/test_freeze.py` fails if either file changes |
| `consent.md` | Consent text shown before the survey starts |
| `instructions.md` | Participant instructions. Deliberately contains **no romanization examples** |
| `cleaning_rules.md` | Pre-registered rules for cleaning responses, fixed before any data is collected |

## Two rules that keep the results honest

**1. `ref_latin` is internal. Never show it to a participant.** It exists so the tooling has a seed for Wikipedia lookups and so the team can read the file. Showing any romanization to participants would push them toward that spelling and destroy the variation we are trying to measure.

**2. The split is frozen before any spelling is written.** Rules are developed on the **train** half only. The test half is opened once, in P4. See `IMPLEMENTATION_PLAN.md` §2.

## Word list design

Each word carries one or more `phenomena` tags, which are the points where romanization actually varies:

| Tag | Variation it targets | Example word |
|---|---|---|
| `long_aa` | long vs. short `a` | प्यार → pyaar / pyar |
| `ee_i` | `ee` vs. `i` | लक्ष्मी → lakshmee / lakshmi |
| `oo_u` | `oo` vs. `u` | पूजा → pooja / puja |
| `v_w` | `v` vs. `w` | विशाल → vishal / wishal |
| `ph_f` | `ph` vs. `f` | फूल → phool / fool |
| `z_j` | `z` vs. `j` (nukta) | ज़िंदगी → zindagi / jindagi |
| `sh_s` | `sh` vs. `s` | श्री → shri / sri |
| `final_a` | the inherent final `a` | राम → ram / rama |
| `aspirate` | `kh gh th dh bh` and `h` placement | सुबह → subah / subeh |
| `nasal` | anusvara as `n` / `m` / `ng` | मुंबई → mumbai / munbai |
| `cluster` | consonant clusters | ज्ञान → gyaan / dnyan |
| `retroflex` | retroflex consonants | पुणे → pune / puney |
| `diphthong` | `ai` / `ae` / `ei` | भाई → bhai / bhaai |
| `doubled` | doubled consonants | सच्चा → saccha / sacha |
| `vocalic_r` | ऋ and र् | ऋतु → ritu / rutu |
| `glide` | `y` glides | प्रिया → priya / priyaa |
| `plain` | low-variance control words | दिल → dil |

`plain` words are controls: if they come back with many different spellings, something is wrong with the instructions or the data.

## Changing this list

Don't, unless the freeze test is failing for a known reason. If a word must change, re-run `tools/freeze_wordlist.py --force`, commit the new `FREEZE.json`, and record why in the commit message. Any change after spellings have been collected invalidates the split, so the honest fix at that point is to leave the list alone.
